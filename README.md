# Central do Assinante EBMU

MVP desenvolvido para a disciplina Projeto de Software — Experiência Prática III.

## Objetivo

Facilitar a jornada digital dos assinantes da EBMU — Evidence-Based Mindfulness University, centralizando orientações sobre acesso aos cursos, gerenciamento de assinatura e suporte.

## Funcionalidades

- Acessar meus cursos
- Minha assinatura
- Problemas para entrar
- Como funciona meu acesso
- Preciso de ajuda

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Arquitetura

Aplicação web responsiva, organizada em três arquivos principais:

- index.html: estrutura e conteúdo das interfaces.
- styles.css: identidade visual e responsividade.
- script.js: navegação e interações.

## Integração com a Hotmart

A Central atua como camada de orientação. A Hotmart permanece responsável pelo processamento de pagamentos, autenticação, gerenciamento de assinaturas e disponibilização dos cursos.

O MVP não armazena credenciais nem processa pagamentos.

## Execução local

Abra o arquivo index.html em um navegador ou utilize a extensão Live Server no Visual Studio Code.

## Controle de versão

O projeto utiliza GitHub para registrar alterações, organizar branches e documentar revisões técnicas por meio de Pull Requests.
